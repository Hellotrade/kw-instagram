# HELLO Crypto photo and clip library

The daily Instagram runs pick pictures from here. Only add files you own or have a license for.

| Folder | What goes in it |
|---|---|
| people/ | Sander, Killer Whales guests and cast, team photos |
| coins/ | Coin and crypto imagery: realistic coins, wallets, trading screens |
| places/ | Places people recognize: Wall Street, Capitol Hill, Times Square, Dubai skyline |
| show-stills/ | Stills from Killer Whales episodes |
| clips/ | Short show clips (mp4, under 100 MB each) for reels |

Name files in plain words, e.g. `people/sander-studio-smiling.jpg`, `clips/ep3-pitch-deal-moment.mp4`. The name is how the runs find the right picture.
